## 1. 视觉目标

### 1.1 一句话

**一块有厚度的、会呼吸的玻璃**：桌面是背景，内容浮在玻璃上；信息密度低、层级靠留白而非分割线；唯一的彩色只用来表达「此刻/可交互」。

### 1.2 六条视觉原则

| # | 原则 | 落地含义 |
|---|---|---|
| V1 | **通透但有底** | 玻璃必须叠在可读的底（scrim/plate）上；文字不直接压在桌面上。可读性优先于透明度。 |
| V2 | **一层光** | 每个玻璃面只有一处高光（顶边 1px + 极淡左上 specular）；不叠第二层装饰光、不用彩色渐变。 |
| V3 | **留白即结构** | 用间距、字号、字重建立层级；不靠边框、底色块、图标堆叠。分割线只在必要处出现。 |
| V4 | **单色为骨，青瓷点睛** | 96% 中性面 + 墨色文字；单一强调色（青瓷）只用在当前状态、焦点、进度、选区。 |
| V5 | **小而精** | 悬浮窗是「一件小器物」：圆角、细高光边、柔和阴影、精确到 1px 的对齐；任何缩放下不破版。 |
| V6 | **静止更高级** | 动效只在有语义时出现，150–220ms，短、轻、无回弹；无装饰性动画。 |

### 1.3 明确不要（反模式）

- ❌ 通用后台模板感：侧边栏、面包屑、卡片网格、彩色标签、统计数字大屏。
- ❌ 渐变堆砌：彩色渐变、霓虹、玻璃拟态+霓虹反光、流光扫过、粒子。
- ❌ 厚重拟物：多层投影、浮雕边、强内阴影、磨砂噪点纹理（产品内不用噪点）。
- ❌ 高饱和色块、红点、角标、优先级色条、任务分类色、庆祝彩带/弹跳/抖动。
- ❌ 整窗全透明 / 文字直接透出桌面（可读性与性能双重风险，见 §6）。
- ❌ 在玻璃上再叠玻璃超过 2 层（模糊嵌套会糊、且 GPU 成本高）。

## 2. 设计 tokens

所有值以 CSS 自定义属性实现；命名与 `docs/prototype-v0.2.html` 一致。浅色为默认主题，深色为对等主题（非简单反色）。

### 2.1 色彩方向

- **整体冷暖：冷调**（中性灰底带一点蓝绿，hue 190–200；深色主题同样偏冷而非纯黑）。
- 理由：玻璃/冰晶的物理直觉是冷、薄、透；冷调中性让唯一的青瓷强调色显得安静而有质感。
- 暖色**只**保留给功能语义（删除/危险、额度提示），且低饱和，不参与装饰。
- 强调色只有一个：**青瓷 Celadon**（hue ≈ 174，低饱和）。不引入第二强调色、不做主题换色。

## 3. 深浅色方案

- 两套对等主题：`data-theme="light"`（默认）/`data-theme="dark"`；深色不是简单反色，而是**降低彩度 + 提高玻璃不透明度**（深色玻璃透出亮壁纸时对比度最危险，见 §12.2）。
- 默认跟随 Windows 应用主题（`prefers-color-scheme` + Tauri 系统主题事件）；是否开放用户手动切换属待定（00 §10.2），本稿不写死；原型里提供演示开关。
- 浅色底不用纯白（`#EDF0F0` 系），深色底不用纯黑（`#14191B` 系）：纯白/纯黑会让玻璃失去「厚度」。
- 切换主题时不做整窗闪烁动画：直接切换 + 150ms 颜色过渡；玻璃高光/阴影同步换套值。
- **禁止**：深浅两种玻璃混用（如深色主题里出现浅色玻璃卡片）；禁止高对比描边（深色主题描边只允许 `line-1/line-2` 两档）。

## 4. 字体与排版

### 4.1 字体栈（只用系统字体，零授权/零下载）

```css
--font-ui:
  "Segoe UI Variable Text", "Segoe UI Variable Display", "Segoe UI",
  "Microsoft YaHei UI", "Microsoft YaHei", "PingFang SC",
  system-ui, -apple-system, sans-serif;
--font-num: "Segoe UI Variable Text", "Segoe UI", "Microsoft YaHei UI", sans-serif;
```

- Windows 11 优先 Segoe UI Variable（可变字重）；Win10 回退 Segoe UI；中文回退微软雅黑 UI。不引入 Inter/思源等需分发字体（ADR-0008）。
- 时间、计数、日期等数字一律 `font-variant-numeric: tabular-nums`，避免跳动。
- 字重只用 `300 / 400 / 500 / 600`；不用 700+（粗体在玻璃上显脏）。大字用 300 制造「轻」。

### 4.2 字号层级

| token | size/line-height | weight | letter-spacing | 用途 |
|---|---|---|---|---|
| `--fs-display` | 26 / 34 | 300 | -0.01em | 主页面日期（A 一天/7 天）、月份 |
| `--fs-title` | 20 / 28 | 500 | 0 | 设置页标题、抽屉标题区 |
| `--fs-section` | 15 / 22 | 600 | 0 | 区块标题（设置分区、弹窗日期） |
| `--fs-body` | 14 / 22 | 400 | 0 | 任务标题、正文、设置行 |
| `--fs-body-sm` | 13 / 20 | 400 | 0 | 抽屉字段、紧凑行 |
| `--fs-meta` | 12 / 18 | 400 | 0 | 时间文字、说明文字、页脚 |
| `--fs-label` | 11 / 16 | 500 | .06em（仅拉丁） | 小标签、轴下区标题、分区小标题 |
| `--fs-micro` | 11 / 15 | 400 | .01em | 已完成剩余时间、日历 +N、刻度 |
| `--fs-widget-title` | 13 / 18 | 500 | 0 | 悬浮窗任务标题 |

### 4.3 中英文与标点

- 界面文案中文全角标点（`，。：？`），时间用半角 `09:00`；数字与中文之间不手动加空格。
- 标题单行省略（`text-overflow: ellipsis`），完整标题在详情抽屉展示；**不允许**压缩字距硬塞。
- 中文不做 letter-spacing（除 label 需要时 ≤.02em）；拉丁小标签可 .06em。

### 5.2 玻璃规则（硬约束）

1. **文字必须有底**：任何信息文字下方 = 玻璃面 + scrim/plate；不允许文字直接落在未加 scrim 的透明层上。
2. **最多两层玻璃**：一处界面最多「底板 + 一层浮层」；浮层内不再使用 backdrop-filter。
3. **模糊与面积匹配**：大面积 28–36px；浮层 40–48px；小控件不用 blur（用半透明纯色更快）。
4. **一层高光**：顶边 1px `--line-glass`；可加一处 8% 白 specular（左上 30% 区域）；高光不超过两处，绝不递归。
5. **不用渐变模拟玻璃**：玻璃感来自「原生模糊 + 半透明 + 高光边 + 阴影」；禁止用灰色渐变画假毛玻璃。
6. **不做整窗全透明**（ADR-0008）：主窗底板 alpha 不低于 0.70，内容 scrim 不低于 0.45；悬浮窗由独立档位控制（§6.2）。
7. **窗内模糊不叠滚动内容滚动时**：滚动容器不设 backdrop-filter（性能）；滚动中的背景模糊只来自窗口本身的 Mica/Acrylic。

### 5.3 主窗「局部玻璃」vs 悬浮窗「毛玻璃」的差异

| 维度 | 主窗 | 悬浮窗 |
|---|---|---|
| 性质 | 工作界面：可读性第一 | 装饰性物件：质感第一 |
| 玻璃占比 | 底板偏实 + 少数浮层玻璃（顶栏/抽屉/弹窗/折叠） | 整窗毛玻璃 + 内容 plate |
| 透明档 | 固定（不开放） | 0.75 / 0.9 / 1.0 档 + hover 提升（config `widget.opacity`） |
| 桌面模糊 | 原生 Mica（Win11）或纯色 | 原生 Acrylic/Mica，降级半透明纯色 |
| 阴影 | 大而淡（窗口级） | 紧凑而清晰（物件级） |
| 圆角 | 16 | 20（固定） |
| 内容密度 | 低（大留白） | 极低（每行 28–32px，最大化留白） |

## 6. Windows / WebView2 实现风险与降级（必须实现）

> 结论先行：**桌面模糊不能靠 CSS `backdrop-filter`**（WebView2 的 backdrop-filter 只能模糊 Web 内容，不能模糊桌面）。悬浮窗的毛玻璃必须走 Tauri `WindowEffects`（Mica Win11 / Acrylic Win10 1903+），CSS 只负责窗内层级。此结论与 `04-architecture.md` §12.1 S4-2 一致。

### 6.1 材质与降级链

**主窗**

1. 首选：无边框 + 窗口透明（`transparent:true, decorations:false`）+ 原生 Mica（Win11）+ CSS 底层 `.78` 乳白玻璃 + 内容 scrim + CSS 圆角/投影。
2. 若透明渲染失败（黑边/白底/闪烁，S4-1）：退回**不透明窗**（`transparent:false`）——底板设为 `--surface-solid`，scrim 100%，保留内部玻璃层（顶栏/抽屉/弹窗仍可用 backdrop-filter 模糊窗内内容）。视觉降级但可用。
3. 若无法无边框（极端兼容）：允许系统标题栏 + 纯色圆角内容区；**不阻塞发布**。

**悬浮窗（降级链，逐级自动 fallback，不报错）**

| 级别 | 条件 | 表现 | 视觉影响 |
|---|---|---|---|
| G1 理想 | Win11 + 透明渲染正常 | Acrylic/Mica + 毛玻璃 + 三档透明度 + 高光边 + 悬浮阴影 | 设计目标态 |
| G2 半透明纯色 | 材质不可用，透明正常 | 无模糊、纯色半透明底板（浅 `.94` / 深 `.92`）+ 同套高光边/阴影 | 少一点「透」，仍是玻璃卡片 |
| G3 不透明 | 透明渲染不可用 | 纯色 `--surface-solid` + 外发丝边 + 阴影（Win11 系统圆角/自绘圆角二选一） | 实心小卡片，仍精致 |
| G4 性能模式 | 用户开启 / 检测到 RDP、虚拟机、低端 GPU | 关闭全部模糊、不透明度取下限（见下）、动效简化 | 明确「兼容外观」 |

- 对应配置：`widget.material = auto|mica|acrylic|solid`（auto 按 Mica→Acrylic→solid 降级）；`widget.reduced_transparency`（性能/兼容模式，ADR-0008 要求必须提供）；实际生效值由 `material_effective` 回传，设置页显示「外观：标准 / 兼容」。
- 首次降级提示（`CLR-E6003`）：**非模态**轻提示一次「当前系统不支持毛玻璃，已切换为兼容外观」，可关闭，不重复弹。
- 降级不改变布局/尺寸/交互，只改变材质与环境光。

### 6.2 透明度档位（悬浮窗）

`widget.opacity ∈ {0.75, 0.9, 1.0}`（config-schema 已定），语义是**玻璃浓度**（越接近 1 越清晰、越不透明），不是窗口整体透明度：

| 档位 | 浅色 surface alpha | 深色 surface alpha | 使用 |
|---|---|---|---|
| 0.75（通透） | 0.58 | 0.62 | 氛围优先；**只允许主文字色**（§12.2） |
| 0.9（标准，默认） | 0.66 | 0.70 | 默认档 |
| 1.0（清晰） | 0.74 | 0.78 | 壁纸花、远程办公、长时间阅读 |

- hover 临时提升到 1.0 档等效 alpha（+0.08，160ms 过渡，不改设置）；鼠标移出 400ms 后回落。
- 内容 plate 追加一层：浅色 `rgba(255,255,255,.16)`，深色 `rgba(14,19,21,.28)`（保证最不利壁纸下主文字 ≥4.5，见 §12.2）。
- **性能模式（G4）**：关闭模糊，浅色 alpha 固定 0.94、深色 0.92；档位选择保留但不生效（或直接禁用控件）；设置页标签「兼容模式」。

### 6.3 性能与稳定性策略

1. 模糊只用在小面积层（顶栏、抽屉、捕捉条≤640×120）；最大面积（主窗底板）交给原生 Mica（便宜）而不是超大 backdrop-filter。
2. **拖拽/缩放窗口期间**给根节点加 `is-moving`：暂停 backdrop-filter、阴影降级，结束后 120ms 恢复（S4-8 验收）。
3. 滚动时不改变模糊；滚动容器不加 filter/backdrop-filter。
4. 动画只做 `transform/opacity/background-color`，不动 `filter/backdrop-filter`。
5. 常驻内存目标 ≤200MB（架构 §8），玻璃层数不随内容数量增长（列表行不带 blur）。
6. 屏幕阅读器/减少动效系统设置下，玻璃不变，动效降级（§7.3）。

### 6.4 验收矩阵（视觉侧）

|---|---|---|
| G-1 | Win11 + 正常显卡 | 无黑边/白底/闪烁；悬浮窗毛玻璃可见；滚动/拖拽无掉帧（S4-1/S4-8） |

## 7. 动效

### 7.1 motion tokens

| token | 值 | 用途 |
|---|---|---|
| `--dur-micro` | 120ms | hover/按下/焦点等即时反馈（不属于「转场」） |
| `--dur-1` | 150ms | 淡入淡出、勾选、捕捉条出现 |
| `--dur-2` | 180ms | 展开/收起、行折叠、弹窗 |
| `--dur-3` | 220ms | 抽屉滑入、视图切换、折叠面板高度 |
| `--ease-out` | `cubic-bezier(.2,.7,.3,1)` | 进入（默认） |
| `--ease-in` | `cubic-bezier(.4,0,.2,1)` | 退出/收起 |
| `--ease-move` | `cubic-bezier(.3,.6,.2,1)` | 位移/抽屉 |
| 上限 | 220ms | 所有有语义的转场 ≤220ms；即时反馈 ≤140ms |

### 7.2 场景

| 场景 | 时长/曲线 | 具体 |
|---|---|---|
| 视图/模板切换 | 150–180ms `ease-out` | 旧内容淡出 90ms → 新内容淡入 + 上移 4px；分段指示器 180ms 位移；**不滑动整页** |
| 完成（主窗） | 150ms | 圆圈描边→勾线绘制（stroke-dashoffset）；标题 90% + 划线 150ms；随后行高收起 180ms 移入折叠（折叠数字 +1 保持文字不弹跳） |
| 完成（悬浮窗） | 150ms + 180ms | 勾出现 → 行折叠消失（≤1s 内，满足 F9）；窗口高度不改（用户尺寸固定） |
| 已完成折叠展开/收起 | 220ms `ease-out` | 高度 0→auto（`grid-template-rows 0fr→1fr` 或 max-height）+ 内容淡入 150ms；chevron 旋转 180ms |
| 详情抽屉 | 200–220ms `ease-move` | `translateX(100%→0)`；遮罩 opacity 160ms；关闭 180ms `ease-in` |
| 日历当天清单 | 180ms | opacity + scale 0.98→1（transform-origin 中心） |
| 捕捉条出现 | 150ms `ease-out` | opacity + translateY(-4px→0)；**热键→可见 <150ms**（M1） |
| 捕捉条收起 | 120–150ms `ease-in` | opacity + 微上移 |
| 新任务落位 | 1800ms 渐隐 | 一次 `--accent-wash` 背景高亮（非动画循环），帮助「接住」感知 |
| 解析中 | 1.2s 循环 | 捕捉条内低频呼吸点（opacity .35→.7），低对比，不阻塞 |
| 主题切换 | 150ms | 颜色过渡，不做整窗闪白 |

### 7.3 降级与禁止

- `prefers-reduced-motion: reduce`（或应用内「减少动态效果」）：所有位移/缩放取消，只保留 ≤150ms 的 opacity 过渡；解析中改为静态省略号；任务落位高亮改为静态 1 次淡出。
- **禁止**：回弹/overshoot、弹跳、抖动、闪烁、流光扫过、视差、庆祝彩带、数字滚动动画、循环发光。
- 动画期间不改变布局之外的元素位置；不做「整页翻转/3D」。

- 第二行（高 24，11px `--text-3`）：左侧状态（`正在听…` / `正在理解…` / 降级提示文案 C07/C08/C09）；右侧 `Enter 提交 · Esc 取消`。
- 语音波形：3 根 2px 竖线，高度 6–14px 循环 1.2s，`--text-3`，低对比；不抢注意力。
- 轻提示（V9）：底部居中、距主窗内容底 24 的胶囊（高 36，圆角 999，`--surface-drawer` + 24 blur + `--shadow-pop`，12px），自动 2.4s 消失；不出现红点/图标弹跳。

## 10. 悬浮窗视觉规格（独立精致小组件）

### 10.1 尺寸与几何

| 项 | 值 | 依据 |
|---|---|---|
| 默认尺寸 | 320 × 220 DIP | config-schema 默认 |
| 可缩放范围 | 宽 260–480 × 高 140–720 | config-schema §2（硬边界） |
| 推荐区间 | 宽 300–400 × 高 200–420 | 本视觉稿建议 |
| 圆角 | 20（固定，缩放不变） | 「小物件」质感，比主窗更圆 |
| 内边距 | 14（宽 <300 时 12） | 保持呼吸感 |
| 头部 | 高 40（高 <200 时 34） | 日期/切换 + 首页图标 |
| 行高 | A 时间轴按刻度；B 30（紧凑 28） | 极低密度 |
| 默认位置 | 主屏工作区右下角，距边 24 | config-schema |

### 10.2 材质与「精致」细节

- 结构：原生 Acrylic/Mica → 窗内半透明底板（§6.2 alpha）→ 内容 plate（浅 `rgba(255,255,255,.16)` / 深 `rgba(14,19,21,.28)`）→ 1px 内高光（顶边最强，向下衰减）→ 外发丝边（1px `--line-glass-outer`）→ `--shadow-float`。
- 顶边 1px 白高光（浅色 .62 / 深色 .14）；左上 30% 区域叠 8% 白 specular（只用一层，不循环）；**不允许**再加斜向高光条/描边光环。
- 阴影比主窗收紧：`0 24px 60px -20px`，避免「贴纸感」；四周均匀，不偏色。
- 内容行无分割线（A 的轴/轴下分隔除外），靠行高与字号分层。
- 缩放时：圆角 20 不变、内边距按 12/14 两档、字号不变（≥260 宽下 12.5/13 可读）；任何尺寸下不重叠、不裁字（超出省略号 + 悬浮显示完整标题由主窗详情承担）。

### 10.3 头部与「进入软件首页」图标

- A 模板头部：左「今天 · 11 月 1 日」（12px，`--text-1` 500/400；不用灰色）；右端 = `home` 图标 16px（描边 1.1，`--text-1`，视觉安静但足 3:1），命中区 28×28，距右/上各 10；hover `--surface-hover` 圆角 8。
- B 模板头部：左 = 「今天 / 全部」小切换（高 22，圆角 7，`--surface-raised`；两项 11px；激活项 `--text-1` 500 + 白/亮底；**不用强调色填充**）；右端同样是 home 图标。
- home 图标是悬浮窗**唯一入口**；无设置齿轮、无关闭按钮、无拖拽把手（按住头部空白拖动即可）。
- 头部整行为拖拽区；图标/切换控件除外（点击优先）。

### 10.4 透明度档位

见 §6.2。视觉验收：0.75 档「明显透出壁纸但文字可读」；0.9 档「能感知壁纸明暗但不影响阅读」；1.0 档「接近实心毛玻璃」。hover 提升只体现在底板 alpha，不改变阴影/图标。

### 10.5 A / B 模板视觉差异

| 维度 | A 时间轴（只有一天） | B 清单（今天 / 全部） |
|---|---|---|
| 头部 | 日期文字 + home | 今天/全部小切换 + home |
| 主体 | 微型时间流：时间 gutter 34px（10px 时间标签，按时间排序；不画整日刻度，避免 320×220 下信息过密）；任务点 = 7px 圆点落在时间线上；时段任务用 `--accent-graphic` 实心点强调；标题 12.5px | 清单行：15px 圆圈 + 标题 12.5px + 右侧时间 10px；无时间轴 |
| 轴下方/尾部 | 1px 分隔线 + 无时间/计数行（圆圈 14 + 标题 12.5 + 计数 10） | 无时间/计数混排在列表尾部（有时间在前） |
| 已完成折叠 | 本稿不画（00 §4 vs Q13 待确认）；若保留则同主窗但行高 28 | 同左 |
| 气质 | 更像「一天的时间切片」，垂直节奏；留白多 | 更像「一张小清单」，横向节奏；信息略密 |
| 数据 | 只一天；范围独立（默认 07:00–23:00，见 config） | 今天/全部由小切换决定，切换即持久化 |

> A/B 只决定摆法、数据同源；悬浮窗不提供模板外入口，切换模板在设置页。

### 10.6 悬浮窗不出现的元素

- 无红点/角标/优先级色块/分类色条；无进度条、无广告/推荐、无统计数字；无系统通知气泡；无「设置」齿轮；无「添加任务」按钮（创建入口 Q11 未定前不放）。

## 11. 状态视觉

> 文案一律复用 `02-ux-spec.md` §13 的 C 编号，不新增产品文案；状态均**非模态、不弹系统通知、不静默失败**。

### 11.1 空态

- A-一天：时间轴照常显示（轴与刻度保留 = 设计过的空），轴区中央偏上放 14px `--text-2`「今天没有安排」+ 12px `--text-3`「按 Ctrl+Alt+Space 说一句」（kbd 键帽 10px）；轴下区收起；已完成 N=0 不显示。
- A-7 天 / A-日历：网格完整保留，格内空；不放大插画。
- B 今天：「今天没有待办」+ 次级提示（C13）；B 全部空：「没有未完成的事」（C14）；全部完成：「都完成了」（C15，正向、不加庆祝动画）。
- 悬浮窗：不空白——头部保留；空态 12px `--text-1`「没有未完成的事」居中偏上，句号省略；home 图标保留。
- 空态不使用插画/大图标（与「克制」一致）。

### 11.2 加载

- 本地数据（主窗/悬浮窗）**不出现整屏 spinner**：同步读取直接渲染；若首帧未就绪，≤1 帧内以纯背景呈现（`--surface-window`），不写「加载中」文案。

- 不设计骨架屏（无网络数据源）；未来若出现异步列表，最多 3 行 60% 灰度骨架，≤300ms。

### 11.3 离线 / 额度用尽 / 识别失败

| 状态 | 位置 | 视觉 | 文案（引用 02 §13） |
|---|---|---|---|
| 离线 | 捕捉条第二行状态区 | 6px `--warn` 圆点 + 11px `--text-3` 文字；无红色、无弹窗 | C08 |
| 离线 | 设置页 AI 服务占位行 | 11px `--text-3` 状态行 + 细点 | C20 类（呈现待 Q14） |
| 额度用尽 | 捕捉条第二行 | 6px `--warn` 圆点 + 11px `--text-3`；输入不丢 | C09 |
| 识别失败 | 捕捉条第二行 | 6px `--warn` 圆点 + 11px `--text-3`；输入保留可重试 | C07 |

### 11.4 完成 / 恢复的视觉

- 完成：圆圈描边淡出 + 勾 1.25px 描边绘制（150ms）+ 标题划线（150ms，`--text-3`），随后行收起（180ms）；主窗移入底部折叠；悬浮窗行消失（≤1s）。
- 勾与划线**用墨色**，不用强调色（高频操作不制造彩色闪烁）；已完成行降到 `--text-3` + 90% 不透明度。
- 恢复：已完成行点击 → 150ms 淡出 + 任务回到原视图 + 轻提示「已恢复」（C19，可选）；不弹确认。

### 11.5 兼容模式 / 减少动效

- 兼容模式：设置页「外观：兼容（性能）」12px `--text-3`；无横幅、无黄色警告条；悬浮窗无角标。
- 减少动效：静默生效，不提示。

## 12. 可访问性底线

### 12.1 对比度（硬底线）

| 元素 | 要求 | 实测（浅色 / 深色，相对 `--surface-solid`） |
|---|---|---|
| 信息文字（14/13/12/11px） | ≥ 4.5:1 | `text-1` 13.57 / 15.54；`text-2` 6.37 / 8.73；`text-3` 5.06 / 6.77 |
| 大字（≥20px 或 ≥18.66px 600） | ≥ 3:1 | `text-1/2/3` 均 ≥5.0 |
| 强调文字（accent） | ≥ 4.5:1 | `#356E69` 5.11 / `#86C0B9` 8.66 |
| 危险文字（danger） | ≥ 4.5:1 | `#8F463E` 5.88 / `#D28A80` 6.49 |
| 焦点环 vs 相邻表面 | ≥ 3:1 | 5.11 / 8.66 |
| 图形（进度弧、选区手柄、点） | ≥ 3:1 | `accent-graphic` 3.39 / 4.90 |

**测量方法**：以 `--surface-solid` 为基准（主窗内容永远有 ≥0.45 scrim，合成色接近 basis）；悬浮窗按 §12.2 的合成矩阵测量。禁止使用 opacity/alpha 削弱文字颜色（`text-2` 不能做成 `text-1` 的 60%）。

### 12.2 玻璃/悬浮窗的对比度保证规则

1. 主窗：所有文字位于 `--scrim-window`（≥.45）之上；实测取 scrim 合成后的最不利色（本规范给出发丝线等非文字元素不参与）。
2. 悬浮窗：**信息文字只允许 `--text-1`**（13/12/11px 同色，靠字号/字重分层）；在 0.9 档 + plate 下，纯黑/纯白壁纸的最不利合成仍 ≥4.5（light 6.2+/dark 5.8+）。若要使用 `text-2`，必须实测通过 4.5 且仅限 0.9/1.0 档。
3. 任何透明度/材质降级不得降低文字对比（降级只会让背景更实，对比更高）。
4. 验收壁纸矩阵：纯黑、纯白、中灰、高饱和照片 × 深浅主题 × 三档透明度（G-4）。

### 12.3 键盘与焦点

- 焦点环：2px `--focus` + 2px offset（用双层 box-shadow 制造与背景的间隙），半径 = 元素圆角 + 2；必须可见于玻璃背景（实测 ≥3:1）。
- 键盘基线（A1，细化待 Q23）：捕捉、完成、恢复、开/关抽屉、删除、模板/子视图切换、框选调整；`Esc` 关闭最上层浮层。
- 所有可点元素有可见 hover + 焦点态；圆形按钮 ≥28×28，行首圆圈命中区 ≥24×24（行高 ≥40 时整行可点区域除圆圈外）。
- 屏幕阅读器可访问名：圆圈「完成：{标题}」；已完成行「恢复：{标题}」；折叠「已完成 N 项，展开」；home 图标「进入软件首页」。

### 12.4 其他

- 不依赖颜色单独传达信息：完成 = 勾 + 划线；计数 = 文字 `2/3`；今天 = 数字加重 + 小点；危险 = 文字「不可恢复」。
- 支持 100%–200% DPI；系统字号缩放不裁字（A7）。
- 支持「减少动态效果」（§7.3）。
- 触控目标最小 24×24（悬浮窗 B 的小切换项命中区 24 高）。
