## 1. 方向变更摘要（v0.2 → v0.3）

| 维度 | v0.2（玻璃） | v0.3（暖纸） |
|---|---|---|
| 基调 | 冷调透明玻璃、晶莹剔透 | **暖调纸面**、奶白留白、柔和圆润 |
| 表面 | 半透明 + 原生 Mica/Acrylic 模糊 | **不透明纸面**：暖纸 + 纯白卡片 + 珍珠灰描边 + 极细噪点 |
| 主题 | 浅色 / 深色 | **雾粉 / 鼠尾草绿 / 雾蓝·石墨** 三套浅色主题 |
| 强调色 | 单一青瓷（冷） | 每主题一套，**只用于小面积**（选中态、完成勾、当前时间线、主题切换、少量按钮） |
| 排版 | 无衬线 + 大留白 | 无衬线正文 + **系统衬线**做日期/大数字/英文 eyebrow（杂志感） |
| 动效 | 150–220ms | **180–260ms**（主题切换 200ms），更慢更克制 |
| Windows 依赖 | 依赖 Mica/Acrylic，需降级链 | **不依赖桌面模糊**；纸面 + CSS 即可交付，实现风险显著降低 |

> 影响：ADR-0008 中“透明玻璃 / 性能模式”的硬要求被本方向弱化，建议 Lead 在 v1.1 审查时更新 ADR-0008 与 windows spike 的验收权重。

## 2. 视觉目标与原则

### 2.1 一句话

**一本摊在桌面上的暖纸日程本**：纸面安静、卡片圆润、线条极细，唯一的颜色只轻轻标记“现在、选中、完成”。

### 2.2 五条原则

| # | 原则 | 落地 |
|---|---|---|
| P1 | **纸感优先** | 大面积 `--paper` + 白色卡片；不用重渐变、不用高饱和色块；噪点极细（≤3%）。 |
| P2 | **圆润但不幼稚** | 卡片 20–24、行 12–16、按钮 10–14；圆角与留白形成柔和节奏，不堆叠气泡。 |
| P3 | **一色一点** | 每主题只有一个强调色；同一屏可见强调元素 ≤3 处；大面积永远奶白。 |
| P4 | **杂志排版** | 日期/大数字用系统衬线；eyebrow 小字距；正文中文无衬线；标题字重统一 500–600、字距统一。 |
| P5 | **慢而克制** | 有意义转场 180–260ms；无回弹/闪光/彩带；减少动效可降级。 |

### 2.3 不要

- ❌ 玻璃拟态/毛玻璃堆叠、霓虹、流光、粒子、重渐变。
- ❌ 通用后台模板：侧边栏、统计卡片、彩色标签、通知角标。
- ❌ 手账贴纸、胶带、手写体、emoji（纸感 ≠ 手账堆砌）。
- ❌ 装饰性大插画、彩色图标、填充图标块。

## 4. 三主题

三套主题**同一结构**，只替换：`--accent-soft`（浅色面）、`--accent-wash`（可承载文字的浅底）、`--accent-ink`（强调文字/勾/线/焦点）、`--accent-tint`（微表面）、`--accent-line`（细描边）。切换过渡 **200ms**（颜色/描边/阴影）。

| 主题 | 名称 | soft | wash | ink | tint | 气质 |
|---|---|---|---|---|---|---|
| 1（默认） | **雾粉** Mist Pink | `#E7D8DC` | `#F6EFF0` | `#8E5B68` | `#FBF7F8` | 温柔、纸感、日常 |
| 2 | **鼠尾草绿** Sage | `#C8D1C7` | `#F1F4F0` | `#526B56` | `#F8FAF7` | 安静、植物感、专注 |
| 3（新增） | **雾蓝 · 石墨** Mist Blue | `#AFC0C8` | `#EDF1F3` | `#5B6B73` | `#F6F8F9` | 冷调、中性、利落 |

### 4.1 第三主题说明（为什么是雾蓝 + 石墨）

- 雾粉/鼠尾草偏柔和，第三套给“不想用粉/绿”的用户：**冷调雾蓝做浅色面，石墨做深色强调**，仍是暖纸底，不破坏整体温度；石墨让完成勾、当前时间线在纸面上足够清晰（`#5B6B73` on `#FAF9F6` = 5.26:1）。
- 满足“三个主题只换强调色/微表面色”的约束：背景、卡片、文字色三套完全一致。

### 4.2 强调色使用规则

- 允许：选中态（模板 tab、子视图、chip）、完成勾、当前时间线、主题切换指示、少量按钮（如“确定”）、计数进度弧、今天标记。
- 禁止：大面积底色、每个任务块的分类色条、装饰性色块、彩色渐变。
- 同一屏可见强调元素 ≤3 处；大面积必须回到奶白纸感。
- 文字/图形对比：`accent-ink` on `paper` ≥5.19:1；on `card` ≥5.46:1；on `accent-wash` ≥4.82:1（三主题均通过，低于 4.82 见 §12）。

### 4.3 主题入口

- 设置页 →「外观主题」三张主题卡（色点 + 中/英名称 + 选中勾）。
- 不在主页面常驻主题按钮；原型顶部为演示快捷切换（非产品 UI）。
- 默认主题：**雾粉**（待用户确认，见 §15 B1）。主题选择持久化（沿用设置 schema 扩展，需 Q 决策）。

## 5. 字体与排版

### 5.1 字体栈（仅系统字体，零外链）

```css
--font-sans: "Segoe UI Variable Text","Segoe UI Variable Display","Segoe UI",
             "Microsoft YaHei UI","Microsoft YaHei","PingFang SC",system-ui,sans-serif;
--font-serif: Georgia,"Times New Roman",Cambria,"Songti SC","SimSun",serif;
--font-num: "Segoe UI Variable Text","Segoe UI","Microsoft YaHei UI",sans-serif;
```

- 中文正文/界面文案：`--font-sans`。
- **系统衬线**只用于：日期大数字（`11.01`）、英文 eyebrow（`SUNDAY · NOVEMBER 1`、`THIS WEEK`、`TODAY'S NOTES`）、月份名、完成计数、少量英文点缀。不使用衬线排中文长句。
- 数字用 `font-variant-numeric: tabular-nums`（时间列、计数）。

### 5.2 字号层级

| token | 值 | 字重 | 字距 | 用途 |
|---|---|---|---|---|
| `--fs-serif-xl` | 42px / 1 | 400 衬线 | .005em | 日期大数字、月份名 |
| `--fs-serif-lg` | 34px | 400 衬线 | .02em | 次大数字 |
| `--fs-title` | 20 / 28 | 600 | 0 | 设置页/抽屉标题 |
| `--fs-section` | 15 / 22 | 600 | 0 | 分区标题 |
| `--fs-body` | 14 / 22 | 400 | 0 | 正文、任务标题 |
| `--fs-body-sm` | 13 / 20 | 400 | 0 | 紧凑行 |
| `--fs-meta` | 12 / 18 | 400 | 0 | 说明文字 |
| `--fs-label` | 11 / 16 | 500 | .06em（仅拉丁） | 小标签 |
| `--fs-micro` | 10.5 / 15 | 400 | .01em | 时间、剩余删除时间 |
| `--fs-eyebrow` | 10 / 14 | 600 | **.20em** | 英文 eyebrow（大写） |
| 悬浮窗 v0.5 | header 10/13.5、行 13、时间 11、footer 11.5 | 400–500 | 行 13 · 500；日期衬线 13.5；时间列 `tabular-nums` | A header：今天 eyebrow 10 + 衬线 11.01；时间点/时间段标记见 §8.11 |

- 标题字重统一：主页面/设置/抽屉标题 600；分区标题 600；正文 400；不使用 700+。
- 英文 eyebrow 一律大写 + `.2em` 字距；中文标题不加字距（除 label ≤.02em）。
- 正文行高 ≥1.5；中文与数字之间不手动空格；时间用半角 `09:00`。

## 6. 间距 / 圆角 / 阴影 / 描边 / 纸纹

### 6.1 间距（只用七档）

`4 / 8 / 12 / 16 / 24 / 32 / 48`。常用：行内 gap 8–14；卡片内边距 20–24；卡片间 16–20；页面水平 padding 40；板块间 32–48。

### 6.2 圆角

| token | 值 | 用途 |
|---|---|---|
| `--r-window` | 24 | 主窗口 |
| `--r-card` / `--r-card-lg` | 20 / 24 | 设置分区、抽屉、悬浮窗、弹窗 |
| `--r-row` / `--r-row-sm` | 16 / 12 | 任务行卡、列表行、内嵌行 |
| `--r-btn` / `--r-btn-sm` | 12 / 10 | 按钮、分段控件、返回键 |
| `--r-block` / `--r-chip` / `--r-field` | 14 / 10 / 12 | 时间块、chip、输入框 |
| `--r-widget` / `--r-capture` | 18 / 24 | 悬浮窗（v0.5 利落卡片）、捕捉条 |

### 6.3 阴影（暖灰、低透明、层叠）

| token | 值 | 用途 |
|---|---|---|
| `--shadow-1` | `0 1px 2px rgba(120,108,92,.05), 0 6px 18px -12px rgba(120,108,92,.16)` | 行卡/小抬升 |
| `--shadow-2` | `0 2px 5px rgba(120,108,92,.04), 0 16px 38px -20px rgba(120,108,92,.22)` | 浮层 |
| `--shadow-window` | `0 3px 10px rgba(120,108,92,.05), 0 34px 80px -34px rgba(110,98,82,.38)` | 主窗 |
| `--shadow-float` | `0 2px 6px rgba(120,108,92,.06), 0 26px 60px -26px rgba(110,98,82,.36)` | 悬浮窗 |
| `--shadow-pop` / `--shadow-capture` / `--shadow-drawer` | 见 CSS | 弹窗/捕捉条/抽屉 |

规则：阴影只表达层级，不用彩色阴影；hover 抬升 ≤2px；不使用多层硬投影。

### 6.4 描边与内高光

- 每个纸卡 = 1px **珍珠灰外描边**（`0 0 0 1px #E9E8E5`）+ **内白高光**（`inset 0 1px 0 rgba(255,255,255,.92)`）。
- 分隔线只用 1px `--line-1`；输入框/圆圈用 1px `--line-2`；不叠加双层边框。
- 焦点环：2px 纸色间隙 + 2px `--accent-ink` 实线（对比 ≥5:1）。

### 6.5 纸纹

- 内联 SVG `feTurbulence` 噪点，`--noise-opacity: .03`（窗口内）/`.05`（桌面示意）；无外部图片、无 CDN。
- 噪点只叠加在纸面与桌面，不做彩色噪点；不影响文字可读性；可关闭（`prefers-reduced-motion` 不触发关闭，低端设备降级见 §13）。

- 白卡（宽 min 620 / 60%，圆角 24，大阴影），顶部 `QUICK CAPTURE · 快速捕捉` eyebrow；麦克风圆钮用 `accent-wash` + accent 图标，录音时低频呼吸。

### 8.11 悬浮窗 v0.5（A 今日议程 / B 清单）

**定位**：一张利落的日程卡片，不是「迷你主界面」。两个模板各自只回答一个问题：
- **A 今日议程**（默认 300×220，≈3:2）：今天接下来要做什么。
- **B 清单**（默认 300×260，≈7:6）：今天 / 全部还剩什么。

**时间语义（v0.5 新增）**

| 形态 | 左侧时间列画法 | 说明 |
|---|---|---|
| 时间点 | 时间后一条 **9px 短横线**（如 `11:30 —`），线宽 1px | 线只属于该时刻 |
| 时间段 | **上下两行时间**（开始 / 结束）+ **两时间之间 6px 细竖线**（1px） | 竖线夹在两条时间之间，不从属整列 |
| 无时间 / 计数 | 时间列留空（不画线） | 不进入 A 收起态主体 |

- 线色 `--line-2` 珍珠灰；仅「当前 / 下一项」可染一点 `accent-ink`（时间文字 + 短线/竖线）；不做装饰、不做贯穿整列的伪时间轴。
- A 收起态只显示**有时间**事项；无时间 / 计数收进「还有 N 件」。

**收起 / 展开（v0.5 新增）**

| 模板 | 收起高度 | 每步增量 | 演示展开上限 | 收起条数 | 展开后 |
|---|---|---|---|---|---|
| A | 220（300×220） | +44 | 396（k=4） | 3 条时间事项 | 全部条目：时间事项在前，无时间 / 计数在后 |
| B | 260（300×260） | +40 | 420（k=4） | 4 条 | 当前 scope 全部条目 |

- 宽度固定 300；**拖底部边缘**（hover 出现的 64×14 把手）向下变高、向上缩回；顶部/头部拖拽移动位置；高度增长时卡片自动上移避免出屏。

- 高度变了但条目不足时按实际条目显示，不留大片空行。

**「还有 N 件」**：**只显示数量，不是展开按钮**；点击 = 切到主窗 Today（B 清单 · 今天），不展开悬浮窗。

**计数任务**：`n/target` 仅作参考；点击 +1 **允许超过目标**（如 `4/3`）；达标**不折叠、不消失**，周期边界（今天/本周结束）才过期（周期实现待 Q6）；chip 达标用 `accent-wash + accent-ink` 强调。

**共同视觉**：96–97% 暖白、1px 珍珠灰、两层柔阴、圆角 18、无纸纹/无模糊；勾选圈 18px/1.25；完成 170ms 淡出（≤200ms）；header 10/13.5、行 13·500、时间 11、footer 11.5；home 14px 唯一入口；footer「＋ 说一句」唤起捕捉条（Q11 建议入口，待产品确认）；三主题只换强调色与微表面；深色 v1 不做。

## 10. 动效

| token | 值 | 用途 |
|---|---|---|
| `--dur-micro` | 120ms | hover/按下等即时反馈 |
| `--dur-1` | 180ms | 淡入、勾选、视线提示 |
| `--dur-2` | 220ms | 视图切换、弹窗、提示 |
| `--dur-3` | 240–260ms | 抽屉、折叠、完成移入 |
| `--dur-theme` | 200ms | 主题切换（颜色/描边/阴影） |
| `--ease-soft` | `cubic-bezier(.22,.68,.36,1)` | 默认进入 |
| `--ease-out-soft` | `cubic-bezier(.25,.8,.35,1)` | 位移/抽屉 |
| `--ease-in-soft` | `cubic-bezier(.4,0,.3,1)` | 退出 |

| 场景 | 时长 | 说明 |
|---|---|---|
| 视图/模板切换 | 180–220ms | 旧淡出 → 新内容淡入 + 上移 8px；不整页横滑 |
| 主页面 ↔ 设置 | 220ms | 设置横向滑入 14px + 淡入；返回淡入 |
| 详情抽屉 | 240ms | translateX 100%→0；遮罩 220ms；关闭 220ms |
| 日历当天清单 | 220ms | opacity + scale .98→1 + 4px 上移 |
| 完成 | 220ms + 220ms | 勾绘制 + 划线 → 行收起移入折叠（≤1s 从悬浮窗消失） |
| 恢复 | 200ms | 行淡出 → 回到视图 |
| 已完成折叠展开/收起 | 240ms | max-height + opacity；chevron 220ms |
| 捕捉条出现/收起 | 200ms | opacity + translateY(-6px→0) |
| 主题切换 | 200ms | 只过渡颜色/描边/阴影（临时 `.theme-switching`） |
| 新任务落位 | 1.8s 渐隐 | 主题 `accent-wash` 高亮，非循环 |
| 当前时间线 | 静态 | 不闪动、不脉动 |

禁止：回弹/overshoot、弹跳、发光、流光、视差、数字滚动、循环装饰动画。`prefers-reduced-motion` 时全部降为 ≤150ms 淡入/直切（主题切换直接切换）。

## 12. 可访问性

### 12.1 对比度（实测，基于 `--paper #FAF9F6` / `--card #FFFFFF`）

| 文字/图形 | 浅色值 | 对比度 | 要求 |
|---|---|---|---|
| 主文字 | `#333532` | 11.76 / 12.06（card） | ≥4.5 ✅ |
| 次要文字 | `#5C5E57` | 6.25 / 6.58 | ≥4.5 ✅ |
| 辅助文字 | `#6E7068` | 4.77 / 5.02 | ≥4.5 ✅ |
| 雾粉 accent-ink | `#8E5B68` | 5.19 / 5.55（card）/ 4.82（wash） | ≥4.5 ✅ |
| 鼠尾草 accent-ink | `#526B56` | 5.55 / 5.84 / 5.27 | ≥4.5 ✅ |
| 雾蓝 accent-ink | `#5B6B73` | 5.26 / 5.53 / 4.87 | ≥4.5 ✅ |
| 主按钮白字 | `#FFFFFF` on accent-ink | 5.46 / 5.84 / 5.90 | ≥4.5 ✅ |
| 删除 | `#8F5B52` | 5.27 / 5.55 | ≥4.5 ✅ |
| 离线/额度点 | `#8A6D3F` | 4.60 | ≥3（图形）✅ |

规则：
1. **不在 `--accent-soft`（#E7D8DC 等）上放小字**：主题浅色面只做装饰/进度/主题色点；可承载文字的是 `--accent-wash`。
2. `--ink-decor` 只用于装饰线/拖拽柄，不承载信息。
3. 纸纹、阴影、hover 抬升不得降低对比；`prefers-reduced-motion` 不改变颜色。
4. 第三主题石墨 `#5B6B73` 作为信息色在纸面上 ≥5.26:1。

### 12.2 键盘 / 焦点 / 命中区

- 焦点环：2px 纸色间隙 + 2px `--accent-ink`（≥5:1）；所有可点元素可见焦点。
- 键盘基线：Tab 顺序 = 顶栏 → 视图切换 → 任务行/圆圈 → 折叠 → 设置；Enter 打开抽屉；Space 完成；Esc 关闭最上层；框选可用方向键调整（细化，Q23）。
- 命中区：圆圈 ≥24、任务行 ≥40、设置按钮 ≥32、主题卡整卡可点。
- 屏幕阅读器：圆圈 aria-label「完成：{标题}」；折叠「已完成 N 项，展开」；首页图标「进入软件首页」。

### 12.3 其他

- 不依赖颜色单独表达：完成 = 勾 + 划线；计数 = 文本 `2/3`；今天 = 日期 + 主题浅底；删除 = 文案「不可恢复」。
- 100%–200% DPI 不裁字；中文正文最小 12px（悬浮窗时间 11px、footer 10.5–11.5px 为例外，仅辅助）。
- 减少动效：系统设置或应用内开关时降级（§10）。

## 13. Windows / 性能与降级（v0.5 更新：悬浮窗去噪点/去模糊 + 高度动画）

- **主路径不依赖桌面模糊**：纸面是不透明表面（`#FAF9F6` / `#FFFFFF`），无需 Mica/Acrylic，不需要窗口 `transparent` 才能成立；v0.2 的 Mica/Acrylic 降级链不再是视觉必需（建议 Lead 更新 ADR-0008 与 spike 验收范围）。
- 若实现希望窗口带轻微纸张半透明：仅作为可选增强，必须保持正文对比度，并允许退回完全不透明纸面；不得依赖 CSS `backdrop-filter` 模糊桌面（WebView2 限制仍成立）。
- 可降级项（低端 GPU / 远程桌面）：关闭主窗/桌面纸纹噪点（`--noise-opacity:0`）、阴影降为单层、关闭悬浮窗实时阴影；布局、圆角、颜色不变。
- 性能预算：噪点使用内联 SVG 平铺（渲染成本低）；避免大面积 `filter/backdrop-filter`；动效只用 transform/opacity/background-color。
- DPI/缩放：100%–200% 布局不破；悬浮窗宽 280 时时间列仍 46px、标题省略；字号最小 10px（footer 11.5）。
