## 1. 一句话

**Clarify 是一个不用部署服务器、以"说一句就安排好"为核心体验的桌面待办软件：想到 → 说 → AI 自动解析并按默认规则排好 → 悬浮窗永远只显示少数要做的事 → 点一下完成 → 24 小时后从视野消失。**

## 2. 产品主张（不可妥协的五条）

1. **零决策捕捉**：捕捉路径上用户只做一个动作（说/写），其余交给默认规则；永远不在捕捉时弹确认框。
2. **不阻塞的纠错**：AI 会出错。默认值可视化、行内可改、10 秒撤销、原文永远保留；用"纠错"替代"确认"。
3. **清晰是规则不是感觉**：用一组硬约束（§3）保证悬浮窗永远干净；"清晰"靠视图过滤与自动归档，不靠用户自律。
4. **AI 隐身**：AI 只做"转写 + 解析 + 默认安排"，不做聊天、不做自动执行、不在后台偷偷调用。
5. **无服务器、数据在手**：没有任何自建后端部署负担；数据存本机；AI 走用户的官方服务激活码（或自带 Key）；隐私边界明示。

## 3. 产品硬规则（v1.1 更新，覆盖旧清晰规则）

1. 事件只有两种状态：**未完成 / 已完成**；"逾期/今天/以后"只是视图分组，不是状态。
2. 已完成在**所有视图底部折叠**，24h 内可恢复，之后**物理删除**。
3. 显示模板只有 **A 时间轴 / B 清单**：A 主窗口一天/7天/日历、悬浮窗仅一天（时间范围可配，主窗与悬浮窗各一套）；B 可切今天/全部。
4. **无**收件箱、标签、项目、优先级、提醒字段、系统通知、备份导出、首次引导。
5. 删除永久不可恢复。
6. 显示模板只决定摆法，不改数据；事件不存"类型"，由字段组合推导。
7. 悬浮窗/列表的条目数量上限、排版、透明度等细节**待视觉初稿确定**（旧"≤5 项"是历史假设，不再作为硬规则）。

## 4. 目标用户与核心场景

- **用户**：25~40 岁知识工作者，Windows 笔记本，事情多且碎片化，用过滴答清单/Todoist 但坚持不下来（整理成本 > 收益）。
- **场景 1**：开会/写代码时想起一件事 → 全局快捷键说一句 → 3 秒内回到手上的事。
- **场景 2**：坐在电脑前，悬浮窗就是"今天的台面" → 点掉一件 → 它消失。
- **场景 3**：晚上打开主窗口看完成了什么、清收件箱里 AI 没把握的几条。
- **场景 4**：纯打字建待办、推迟一件事、到点提醒。

## 5. 成功指标（v1 量化目标）

| 指标 | 目标 |
|---|---|
| 热键 → 捕捉条出现 | < 150 ms |
| 10s 语音端到端（转写+解析+卡片出现） | ≤ 4 s P95（云端正常网络） |
| 解析时间字段准确率（评估集） | ≥ 90%，且幻觉日期 = 0 |
| JSON 合法率 | ≥ 99% |
| 首次捕捉成功率（新用户首日） | ≥ 90% |
| 崩溃/无响应率 | < 0.5% 会话 |
| 单次捕捉 AI 成本 | < ¥0.02（按厂商现价） |
| 用户日常操作决策点 | 创建 0 次、清理 0 次 |

## 6. 范围

### v1 要做（P0）

- 全局快捷键捕捉（语音/文字二合一）；本机录音 + 云端 ASR + DeepSeek 解析 + 乐观 UI
- 官方 AI 服务（激活码 + 额度）为主，BYOK 兜底，离线规则模式
- 悬浮窗：今日 / 下一条 / 收件箱三种模式 + 窗口行为设置
- 主窗口：今日 / 收件箱 / 全部 / 已完成 / 悬浮窗 / 设置
- 任务：单实体、4 状态、完成/撤销、重复任务、24h 软归档 30 天可恢复
- 提醒：到点通知、托盘常驻、开机自启、睡眠补发、免打扰
- 首启引导、托盘、单实例、自动更新、数据备份/导出/回收站
- 命令面板 + 页内搜索

### v1 明确不做

- 自建服务器/账号体系/多端同步；公开分发的合规体系（延后）
- 本地 ASR、流式字幕、AI 聊天、语音改期/删除等写操作、后台自动 AI 调用
- 自定义清单/项目层级/看板、团队协作、移动端、日历双向同步

### 阶段

内测（自用 + ≤20 人）→ 公开分发（需合规/收费评估）→ 远期（同步/本地模式/多端）。

## 7. 角色与决策权

| 角色 | 职责 | 决策权 |

## 10. 协作规则

- **单一事实源**：同一事实只在一份文档定义，其他文档链接引用。
- **改行为必改文档**：PR 必须同步更新对应文档，否则不合并。
- **ADR**：影响架构/依赖/契约/成本的决定必须写 ADR（背景/选项/决定/后果）。
- **文档 v0.1 → 评审 → 冻结**：先求可执行，再求完备；禁止无 Owner 的文档。
- **秘密管理**：真实 API Key/激活码/密码一律不进仓库；`.env` 进 `.gitignore`；日志脱敏。
- **评审**：每阶段一次红队审查（一致/遗漏/可执行性），问题清单落档并关闭。

## 11. 关键假设（未确认前按默认执行）

1. 1 名开发（初级可承接）+ AI 代理辅助；无专职设计/QA。
2. Windows 优先；macOS 延后。
3. 先自用 + ≤20 人内测；公开分发/收费延后。
4. 用户接受注册两家 AI 服务账号（ASR 厂商 + DeepSeek）并承担小额费用。
5. 用户接受"音频上传 ASR、文本上传 DeepSeek"的隐私边界（首启明示）。
6. 月预算上限 ¥200 作为初始保护。
