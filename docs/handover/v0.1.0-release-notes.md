# Clarify 0.1.0 开发版说明（M1–M3）

> 第一个可安装包，用于真实试用主流程。视觉已按 v1.0 方向做了一轮打磨；仍属开发版，数据只在本机。

## 安装

- 安装包：`target/release/bundle/nsis/Clarify_0.1.0_x64-setup.exe`
- 当前未做代码签名，Windows SmartScreen 可能提示；点「更多信息 → 仍要运行」
- 安装到当前用户，默认创建开始菜单快捷方式

## 已有功能

- 主窗口：A 时间轴（一天/7天/日历）、B 清单（今天/全部）、详情抽屉（编辑/删除/计数）、已完成折叠与恢复、三主题
- 悬浮窗：独立置顶，A 今日议程 / B 清单，时间点短线 / 时间段竖线，点击任务完成、计数 +1，drag 底边调高度
- 全局热键：
  - `Ctrl+Alt+Space`：文字捕捉（聚焦输入框）
  - `Ctrl+Alt+V`：语音捕捉开始/停止
- 语音：豆包流式识别 2.0 → DeepSeek 解析 → 自动创建
- 文字：DeepSeek JSON 解析；失败自动回退规则解析
- 完成 24h 后可恢复，之后物理清理；重复任务推进下一次；计数允许超额（4/3）并按日/周复位
- 主窗/悬浮窗位置与尺寸记忆；关闭主窗 = 隐藏，设置页有「退出 Clarify」

## 首次配置 AI

设置（⚙）→ AI 服务：

- DeepSeek API Key：`sk-...`
- 豆包语音 API Key（豆包语音控制台签发）
- 保存后只存本机 `%LOCALAPPDATA%\com.clarify.desktop\ai-config.json`（开发期明文；正式版迁移 Windows 凭据管理器）

语音依赖豆包语音控制台已开通「大模型流式语音识别」（`volc.seedasr.sauc.duration` 或 concurrent）。

## 已知限制

- 单显示器居中/主屏恢复；多屏切换后的窗口夹取还未做
- 悬浮窗固定宽 300；B 视图最大高度 420（按视觉 v1.0）
- 无托盘图标（按产品决策）、无通知、无备份/导出、无夜间模式
- 语音识别会显示最终文本，不做逐字流式上屏
- AI Key 开发期明文存 AppData；请勿把安装目录/配置文件发给别人
- DeepSeek/豆包均为外部服务，费用由各自账号承担

## 建议试用路径

1. 打开 Clarify → 按 `Ctrl+Alt+V` 说「明天下午三点跟张总开会，顺便买牛奶」→ 再按一次 `Ctrl+Alt+V`
2. 看悬浮窗和主窗是否出现两项；点悬浮窗任务勾掉一个
3. 调一下悬浮窗底边高度、拖动位置，重启应用确认记忆
4. 设置 → 退出 Clarify；再打开，确认主窗/悬浮窗回到原位
