# Clarify 0.1.0 开发版说明（M1–M3，反馈修复版）

> 第一个可安装包，用于真实试用主流程。本版根据第一轮体验反馈修复了悬浮窗刷新/折叠/底部操作与设置页。仍属开发版，数据只在本机。

## 安装

- 安装包：`target/release/bundle/nsis/Clarify_0.1.0_x64-setup.exe`
- 当前未做代码签名，Windows SmartScreen 可能提示；点「更多信息 → 仍要运行」
- 安装到当前用户，默认创建开始菜单快捷方式

## 已有功能

- 主窗口：A 时间轴（一天/7天/日历）、B 清单（今天/全部）、详情抽屉（编辑/删除/计数）、已完成折叠与恢复、三主题
- 悬浮窗：
  - 展开为卡片：**今日任务优先 + 未来任务（显示日期）+ 无时间/计数任务**；主窗/语音创建后**实时刷新**
  - 头部「—」收起为 64×64 圆形符号（带数量角标），点击符号展开；记住上次高度
  - 底部 **麦克风 + 笔**：麦克风直接录音（再点一次结束）→ 识别 → 创建；笔打开主窗口 Today
  - **拖标题栏移动；底边常驻握把拖动调高度**；位置/尺寸/折叠状态跨重启记忆
- 全局热键：
  - `Ctrl+Alt+Space`：文字捕捉（聚焦输入框）
  - `Ctrl+Alt+V`：语音捕捉开始/停止
- 语音：豆包流式识别 2.0 → DeepSeek 解析 → 自动创建
- 文字：DeepSeek JSON 解析；失败自动回退规则解析
- 完成 24h 后可恢复，之后物理清理；重复任务推进下一次；计数允许超额（4/3）并按日/周复位
- 设置页：外观主题、**A/B 视图直达**、窗口与退出；返回按钮在**右下角**
- 主窗/悬浮窗位置与尺寸记忆；关闭主窗 = 隐藏，设置页有「退出 Clarify」

## AI（官方网关，客户端不含 Key）

- 客户端不再内置任何 API Key；语音识别 / 文本解析都调用官方网关
- 网关地址：`https://clarify-gateway-dsidnsbafc.cn-hangzhou.fcapp.run`
- 免费额度：每设备每天 **5 次解析 + 30 秒语音**；设置页可输入激活码加量
- 额度在客户端本地计数；技术用户理论上可绕过。早期公开版可接受，有量后加服务端额度
- 设置页「额度」可查看今日剩余、输入激活码
- 语音/文字会经网关发送到豆包/DeepSeek 处理；待办数据仍只在本机

## 已知限制

- 单显示器居中/主屏恢复；多屏切换后的窗口夹取还未做
- 悬浮窗宽 300；收起 64×64；展开高度 180–420
- 无托盘图标（按产品决策）、无通知、无备份/导出、无夜间模式
- 语音识别会显示最终文本，不做逐字流式上屏
- 安装包未签名；Key 编译进 exe（个人使用；公开发行前需切官方网关）
- DeepSeek/豆包均为外部服务，费用由各自账号承担

## 建议试用路径

1. 开始菜单打开 Clarify
2. 悬浮窗点「—」变成符号，再点符号展开
3. 点悬浮窗麦克风说「明天上午十点开产品会」，再点一次麦克风结束
4. 看主窗和悬浮窗是否出现任务；拖动悬浮窗标题栏、拉底边调高度
5. 设置 → 点 A / B 直达视图；右下角返回
6. 关主窗 → 从开始菜单重开，确认窗口位置记忆
