# ADR-0001（拟议，待拍板）：AI 能力由谁提供、API Key 放在哪

- 状态：Proposed（草案，等待用户决策）
- 日期：2026-11-01
- 关联：`docs/design-v0.3.md` §8

## 背景

产品承诺"用户不需要部署服务器"；同时有两个目标：

1. 任何安装了这个软件的人，打开就能用上好的语音识别和解析（**零配置**）；
2. 你（作者）不想运维服务器，也不想被 API 账单和 Key 泄露拖垮。

用户反馈：希望语音识别效果更好，对"本机小模型"的识别质量不放心。

## 核心矛盾：三个诉求不可兼得

| 诉求 | 含义 |
|---|---|
| ① 零配置 | 用户不填 API Key、不注册账号 |
| ② 零后端 | 你不出服务器/不运维 |
| ③ 零风险零成本 | Key 不泄露、API 费用不归你 |

**任意方案最多满足其中两个。**

## 候选方案

### A. BYOK：每个用户用自己的 API Key（客户端直连厂商）

- 满足 ②③；不满足 ①（要配置一次）
- 效果：大厂云端质量，最好；可"同一厂商一个 Key 同时用于语音识别 + 解析"
- 成本：用户自己承担（一天几十次通常不到几毛钱，需按厂商现价核实）
- 最大摩擦：非技术用户注册厂商、找到 Key 这一步容易卡住（需要图文向导 + 国内厂商预设）

### B. 官方代理：你提供薄服务器/Serverless 网关，Key 只存在服务端

- 满足 ①；不满足 ②③（要跑一个服务；你付 API 费用）
- 体验：任何人安装即用、质量一致最好；可加激活码/设备绑定/每日额度/付费订阅
- 技术形态可以很轻：Cloudflare Workers/阿里云函数计算等 Serverless，不用维护 VPS，但仍然是"有一个服务在跑"，有部署步骤
- 风险：滥用（需配额和风控）、持续账单（按用户量线性增长）、公开分发涉及合规（生成式 AI 服务备案/隐私政策/内容安全，需评估；自用/小范围内测不涉及）
- Key 安全：因为 Key 不在客户端，比"内置 Key"安全得多

### C. 内置作者 Key（自用/小圈子）

- 满足 ①②；不满足 ③
- 客户端里的 Key 会被抓包/调试提取（混淆只能拖时间），一旦被传播 → 账单失控、账号可能被封
- 只适合：自己用、或几个完全信任的人；**绝不公开分发**
- 可以先给 Key 设消费预算上限，把最坏情况封顶

### D. 混合：BYOK 免费版 + 官方体验额度（邀请码/限量），后续订阅

- 需要 B 的服务器能力，但把"任何人能用"先做成有限体验
- 适合"先验证产品价值、再谈商业化"的路线

## 推荐

| 你的实际情况 | 推荐 |
|---|---|
| 只自己用 / 家人朋友几个人用 | **C（内置你的 Key，设预算上限）+ 可选 A**，最快跑起来 |
| 想做成给任何人用的产品 | **从 v1 就按 B 设计**：客户端只认"AI 网关 base URL + 设备激活码"，API Key 永不下发客户端；ASR 与 LLM 都走网关 |
| 现在不确定，想先验证 | **A 先跑**（无服务器、零风险），同时把"AI 网关 base URL"做成可切换配置，将来加 B 不改业务代码 |

**无论选哪条**：客户端必须做"AI 网关抽象"——把 BYOK 和官方代理做成两个 provider 实现，业务代码不感知，后期切换零成本。

## 语音识别质量（与上面的方案正交）

- 本机小模型（SenseVoice-Small 228MB）：免费、离线、音频不出电脑；但在口音、噪声、中英混说、长句上不如大厂云端——"感觉不好"是合理的怀疑。
- 云端 ASR（阿里云百炼、火山引擎、讯飞、OpenAI 等）：中文识别质量最好且一致；需要上传音频、按量计费、依赖网络。
  - 同一厂商账号通常可同时调用 ASR 与 LLM（如阿里云百炼的 Paraformer + Qwen、火山引擎的语音识别 + 豆包、OpenAI 的 gpt-4o-transcribe + GPT），所以 **BYOK 用户也只需要配置一个 Key**。
  - 具体接口兼容性/价格需 spike 核实（阿里云 Paraformer 为自有 REST/WS 协议，非 OpenAI 兼容；OpenAI 的 audio API 为 multipart 上传）。
- 建议：用 **20 条真实录音**（你的口音、你的麦克风、你的环境）做 A/B：本机模型 vs 2~3 家云端，按"准确率/可读性/延迟/价格"选，不靠感觉。

## 待用户确认

1. 这软件是**自用**还是**以后给别人用**？
2. 如果"任何人装了都能用"，你能接受**每月为 API 付一笔钱**（随用户量增长）并接受"需要一个小型服务端"吗？
3. 你平时有没有已注册的厂商账号（DeepSeek / 阿里通义 / 火山豆包 / OpenAI / 其他）？有的话先用那家做 spike。
4. 语音识别：云端（效果最好，音频上传）还是本机（免费离线，效果弱一些）还是"云端为主 + 本地兜底"？
