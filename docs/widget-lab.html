悬浮窗特写 —v0.4 · 2026.11

这版把悬浮窗当一张日程卡片，而不是「迷你主界面」。A 今日议程只回答「今天接下来做什么」：主体最多 3 条有时间事项，时间列右对齐，无时间/计数收进底部「还有 N 件」。B 清单只回答「今天 / 全部还剩什么」：最多 4 条，超出以 +N 收口。固定横比例让它在桌面上是卡片，不是面板。

视觉上做减法：96–97% 暖白、1px 珍珠灰、两层柔和阴影，去掉纸纹与重模糊，让边缘与文字更脆；时间列 46px 右对齐 + tabular numerals、18px 细环、13/500 标题构成清晰层级；只有「当前 / 下一项」用一点强调色；拖拽把手与 resize 角只在 hover 时出现。点「＋ 说一句」在正式原型中唤起捕捉条（Q11 建议入口，最终以产品确认为准）。

DESIGN NOTES

为什么更利落

01 · 信息层级

一个卡片只回答一个问题

A 主体只放「有时间」的事项，最多 3 条；无时间 / 计数不混入主体，收进「还有 N 件」。B 主体只放清单，最多 4 条，超出 +N。时间列与勾选圈之间不再有伪时间轴竖线，改用「时间 → 勾选 → 标题」三段固定网格，扫读更快。

02 · 质感与细节

更脆：去掉模糊与纸纹

小组件面积小，噪点和半透明反而显糊。改为 96–97% 暖白 + 1px 珍珠灰 + 两层柔阴 + 内白高光；时间列 tabular numerals，勾选圈 18px/1.25px；仅当前项用一点主题色。footer 提供「＋ 说一句」入口，拖拽把手 / resize 角只在 hover 出现，静态截图更干净。
