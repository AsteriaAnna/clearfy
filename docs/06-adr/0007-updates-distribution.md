# ADR-0007：更新与分发

- 状态：Proposed
- 日期：2026-11-01
- 关联：`11-release-ops.md`、`08-engineering.md`

## 背景

无服务器约束下，更新与分发也不能依赖自建后端；目标先用 Windows，公开发布延后。

## 决策（建议）

- 安装包：NSIS/MSI；v1 内测可暂不签名（需提示"未知发布者"），公开前必须签名。
- 更新：**GitHub Releases + 静态 `latest.json` + Tauri updater**，不自建更新服务器；国内需备用下载页（手动安装包）。
- 版本：语义化版本；数据库 schema 带 `schema_version`，升级需兼容旧数据（不做备份，所以迁移必须可靠）。
- 不做：自动备份/导出、云同步、遥测、崩溃上报。
- 公开分发前：隐私政策/用户协议/第三方许可页/生成式 AI 合规评估。

## 后果

- 正面：零运维；GitHub 免费。
- 负面：依赖 GitHub 可达性；数据库迁移失败不可回滚（无备份），必须做迁移前自检与只读演练。
