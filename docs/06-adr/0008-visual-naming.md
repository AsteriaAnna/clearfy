# ADR-0008：视觉方向与命名

- 状态：Proposed（视觉细节待初稿评审）
- 日期：2026-11-01
- 关联：`00-product-decisions.md` §8；`02-ux-spec.md`

## 背景

用户给出的视觉方向：**透明玻璃、极简、克制、留白、高级感、当代艺术品、晶莹剔透**；悬浮窗虽是小组件但要足够精致。名字 Clarify 继续使用，但公开前需查商标。

## 决策（方向）

- 主窗口：大面积留白 + 局部玻璃卡片；不做整窗全透明（可读性与性能）。
- 悬浮窗：独立透明/毛玻璃小组件，圆角、细高光边、轻阴影；可移动、可缩放；不使用皮肤系统。
- 颜色：低饱和、单一强调色；具体色值待视觉初稿。
- 字体：优先系统字体（Segoe UI Variable / 微软雅黑），不引入需授权字体；字重与字号层级克制。
- 动效：少而慢（150~220ms，缓动），只用于完成/折叠/视图切换等有意义的反馈。
- 透明/模糊必须提供"性能模式"降级（关闭模糊/降低透明度），并兼容 Win11 之外的显卡。
- 名字：内部代号 Clarify；公开前查商标与域名，必要时改名。

## 后果

- 正面：视觉语言统一、有辨识度；小组件精致。
- 负面：透明+模糊在 Windows 有性能与兼容风险；需要视觉初稿与用户共同调整。
- 具体 tokens（色值/圆角/间距/阴影/字体大小）在视觉初稿中定义。
