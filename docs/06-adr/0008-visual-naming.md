# ADR-0008：视觉方向与命名

- 状态：**Accepted（2026-11-01 冻结视觉 v1.0）**
- 日期：2026-11-01
- 关联：`00-product-decisions.md` §8/§12.3；`12-visual-spec.md`；`prototype-v0.5.html`

## 决策（已冻结）

- **色板**：主背景 `#FAF9F6`、纯白卡片 `#FFFFFF`、珍珠灰 `#E9E8E5`、奶杏 `#E9DBCE`、雾粉 `#E7D8DC`、鼠尾草绿 `#C8D1C7`、主文字 `#333532`。
- **风格**：暖纸感 + 纯白纸卡 + 珍珠灰描边 + 柔和层叠阴影 + 内白高光 + 极细噪点；柔和圆润细节（milooni 方向）+ 日程本/planner 的优雅排版（Planbella 方向）。
- **主题**：雾粉（默认）/ 鼠尾草绿 / 雾蓝·石墨（第三主题，适合中性/男性偏好）；同结构只换强调色，200ms 过渡；v1 不做夜间模式。
- **字体**：中文系统无衬线（Segoe UI Variable/微软雅黑）；日期、大数字、英文 eyebrow 用系统衬线（Georgia）。
- **悬浮窗（v1.0）**：A 300×220 / B 300×260，宽固定 300；时间点=时间后 9px 短横线，时间段=上下两行时间+6px 细竖线；底边下拉按行高步进（A 44/B 40），最高 A 396/B 420，显示全部并隐藏「还有 N 件」；超高内部滚动；高度跨重启记忆；「还有 N 件」点击跳主窗 Today（保持上次模板 + 今天）。
- **Windows**：主窗采用不透明纸感，不依赖 Mica/Acrylic；悬浮窗轻半透明，提供"毛玻璃→半透明纸→纯色"降级与减少动效。
- **命名**：内部代号 Clarify；公开前查商标与域名。

## 后果

- 正面：视觉语言统一、有辨识度；主窗透明风险消除；三主题可换肤。
- 负面：视觉细节仍需在实现中打磨；衬线/噪点需按性能降级；公开前需商标确认。
