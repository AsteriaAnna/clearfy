# ADR-0006：密钥、隐私与激活

- 状态：Accepted
- 日期：2026-11-01
- 关联：`00-product-decisions.md` §9；`05-contracts/config-schema.md`

## 背景

官方网关模式下，厂商 Key 不能下发客户端；BYOK 模式的 Key 也不能明文落盘。同时产品涉及音频与文本上传第三方。

## 决策

- **官方模式**：厂商 Key 只存阿里云函数计算环境变量；客户端只存激活码 + 设备 ID；激活码可批量生成、吊销、设额度。
- **BYOK 模式**：Key 存 Windows 凭据管理器（DPAPI），不写配置文件、不进日志、不随安装包分发。
- **音频**：客户端录音后上传 ASR（官方网关或用户自配）；服务端/网关不落盘音频；转写完成即丢弃。
- **文本**：转写结果发 DeepSeek 解析；网关不记录正文，只记状态码/延迟/用量。
- **无遥测、无账号、无云同步、无备份导出**。
- 隐私告知必须出现在界面（**无首启引导**，具体位置待定：设置页/悬浮窗菜单/详情页脚注）。
- 公开分发前的合规（生成式 AI 备案等）延后评估。

## 后果

- 正面：Key 泄露风险最低；用户数据边界清晰。
- 负面：用户需信任作者网关；BYOK 用户需自行管理 Key；隐私告知位置需产品决定。
- 网关必须做日志脱敏与配额，防止被刷。
