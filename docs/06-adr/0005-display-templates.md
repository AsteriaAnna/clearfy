# ADR-0005：显示模板与视图规则（A 时间轴 / B 清单）

- 状态：Accepted
- 日期：2026-11-01
- 关联：`00-product-decisions.md` §5；`02-ux-spec.md`

## 背景

用户希望显示方式可选且极简：数据层不存"类型"，视图是渲染层分组规则；不想被 24 小时铺满。

## 决策

- 只做两种模板，数据同源：
  - **A 时间轴**：主窗口可切一天 / 7 天（周视图，7 列）/ 日历（月历网格）；悬浮窗只有一天。
    - 时间范围可配置（不默认 24h 全展示）：设置里用**自由拖拽选区（像截图，框外变暗）**；主窗与悬浮窗各配一套。
    - 选区边界撞到时段任务中间时，自动把该任务**完整包进来**，不裁半条。
    - 时间点与时间段任务都上轴；轴下方放无时间/计数类事项。
    - 日历格显示已安排任务，只写"要做什么"，每格最多 3 个；点击某天弹出当天清单。
  - **B 清单**：今天 / 全部可切；主窗通过视图切换；悬浮窗里用一个小切换控件。
- 不做 C 极简卡片模板。
- 事件不存类型；显示由字段组合推导。
- 已完成在所有视图底部折叠，点击可恢复。

## 后果

- 正面：同一份数据多种看法；实现集中在一个渲染层；可扩展。
- 负面：渲染优先级规则必须定义（时间点/时段/重复/计数如何排列）；时间范围选区交互有实现复杂度。
- 视觉方向为透明玻璃/极简，具体 tokens 待视觉初稿。
