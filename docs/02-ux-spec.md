## 1. 设计原则（界面验收依据）

| # | 原则 | 界面含义 | 来源 |
|---|---|---|---|
| P1 | 极简 | 主窗只有一个主页面；完成区只有"未完成/已完成"；不出现分类器 | 00 §1、§6 |
| P2 | 克制、留白 | 大量留白、少用颜色、单一强调、无装饰性元素 | 00 §8 |
| P3 | 透明玻璃、晶莹剔透、高级感 | 半透明玻璃层次、细高光描边、柔和阴影；不用厚重拟物与高饱和色块 | 00 §8 |
| P4 | 零决策 | 捕捉与完成路径 0 确认；不弹模式选择、不弹"本次/系列" | 00 §3、§7 |
| P5 | AI 隐身 | AI 只在用户触发时出现；处理中不阻塞、不弹窗、不聊天 | 00 §3；10-risks R9（不做后台自动调用） |
| P6 | 消失可预期 | 已完成 24h 后删除，界面持续显示剩余可恢复时间；不靠突袭 | 00 §4 |
| P7 | 不抢注意力 | 无系统通知、无红点/角标/优先级色块；动效短、轻、可关 | 00 §9、§8 |
| P8 | 两模板数据同源 | A/B 只是摆法，任何视图里看到的是同一批任务 | 00 §5 |

## 2. 信息架构与页面地图

### 2.1 结构树

```
Clarify
├─ 主窗口
│  ├─ 主页面（唯一主页面，无侧边栏多页面）
│  │  ├─ 顶栏：模板切换 [A 时间轴 | B 清单] + 子视图切换 + 设置入口
│  │  ├─ 内容区
│  │  │  ├─ 模板 A：一天 / 7天 / 日历（三选一）
│  │  │  └─ 模板 B：今天 / 全部（二选一）
│  │  ├─ 已完成折叠（主窗所有视图底部；悬浮窗见 Q13 临时默认）
│  │  ├─ 右侧详情抽屉（点任务行打开，覆盖在内容区上）
│  │  └─ 日历当天清单弹窗（点日历某天打开）
│  └─ 设置页（从主页面进入，独立一页；无首启引导）
│     ├─ 时间范围（主窗 A）
│     ├─ 悬浮窗（含悬浮窗 A 时间范围）
│     └─ AI 服务（激活/额度/BYOK/规则/隐私；呈现待定 Q14/Q15）
├─ 悬浮窗（独立窗口，可移动、可缩放）
│  ├─ 模板 A：一天（时间范围独立配置，无子视图切换）
│  ├─ 模板 B：今天 / 全部（小切换控件）
│  ├─ 「进入软件首页」图标
│  └─ 已完成折叠（**Q13 待用户确认**；临时默认：不含折叠，见 `10-risks-decisions.md` §3）
├─ 捕捉条（全局浮层，Ctrl+Alt+Space）
└─ 时间范围选区浮层（设置页触发，截图式拖选）
```

**结构约束（已定）**：主窗 = **一个主页面 + 设置页**；不拆"今日/全部"两个页面；不做侧边栏多页导航；**不做首次启动引导**（打开即主页面）。

### 2.2 页面/浮层清单

| # | 名称 | 类型 | 进入方式 | 退出方式 | 职责 | 状态来源 |
|---|---|---|---|---|---|---|
| V1 | 主页面 | 主窗口页面 | 启动应用（无引导） | 关闭窗口=隐藏（Q20 临时默认，待用户确认）；退出入口见 §10.4 | A/B 模板浏览、完成、打开详情 | 本机 SQLite |
| V2 | 设置页 | 主窗口页面 | 主页面顶栏设置图标 | 返回主页面 | 时间范围、悬浮窗、AI 服务 | 本机设置 |
| V3 | 详情抽屉 | 右侧覆盖浮层 | 主页面点任务行 / 日历弹窗点任务行 | 关闭按钮、`Esc`、点击遮罩 | 编辑标题/时间/重复/计数；删除 | 选中任务 |
| V4 | 已完成折叠 | 内容区底部内联区域 | 默认收起，点 header 展开 | 再点收起 | 展示 24h 内完成记录、点击恢复 | 本地完成记录 |
| V5 | 日历当天清单弹窗 | 模态浮层 | 日历视图点某天格子 | `Esc`、点击外部、关闭按钮 | 当天任务清单 + 该天已完成折叠 | 当天任务 |
| V6 | 悬浮窗 | 独立窗口 | 常驻/`Ctrl+Alt+W` 显隐 | `Ctrl+Alt+W` 隐藏、应用退出 | A 一天或 B 今天/全部 + 完成 | 本机 SQLite |
| V7 | 捕捉条 | 全局浮层 | `Ctrl+Alt+Space` | 提交、`Esc` 取消 | 语音/文字捕捉 | 输入中 |
| V8 | 时间范围选区浮层 | 全屏浮层 | 设置页点"框选" | 确定/取消 | 截图式拖选时间范围 | 当前范围配置 |
| V9 | AI 状态/结果轻提示 | 非阻塞轻提示 | 捕捉完成/失败时 | 自动消失（细化） | 告知结果/降级状态，不阻塞 | 解析结果 |

### 2.3 跳转规则

1. 启动应用 → **直接进入 V1 主页面**（无引导、无欢迎页、无设置拦截）。
2. 捕捉条 V7 是**全局浮层**：在任何界面（含悬浮窗）按 `Ctrl+Alt+Space` 都可唤起；捕捉完成**不跳页**，结果直接落到当前视图（若当前视图不包含该任务，用 V9 轻提示告知摘要）。
3. 点任务行 → V3 详情抽屉（覆盖，不换页）；关闭抽屉回到原视图与原来的滚动位置。
4. 日历点某天 → V5 弹窗（不换页）；关闭后回到原日历视图、原月份。
5. 主页面 ↔ 设置页：设置页有明确返回；离开设置页回到主页面原状态。
6. 悬浮窗「进入软件首页」图标 → 打开/聚焦 V1 主页面（不是设置页）。
7. `Esc` = 关闭**最上层**浮层/抽屉/弹窗/捕捉条；无浮层时是否退出应用：**不绑定**（避免误退，细化）。

## 3. 主窗口框架

### 3.1 布局骨架

```
┌──────────────────────────────────────────────────────────────────────┐
│  [ A 时间轴 ] [ B 清单 ]                            [一天][7天][日历]  ⚙ │  ← 顶栏
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│                              内容区（模板 A 或 B）                     │
│                                                                      │
│  ────────────────────────────────────────────────────────────────    │
│  ▸ 已完成 3                                                          │  ← 已完成折叠
└──────────────────────────────────────────────────────────────────────┘
```

- 顶栏左侧：**模板切换 A/B**（分段控件，已定：主页面顶部 A/B 视图切换）。
- 顶栏中部/右：**子视图切换**（上下文出现：A 显示 一天/7天/日历；B 显示 今天/全部）。
- 顶栏最右：**设置入口**（图标按钮，细化位置；设置页是唯一管理入口）。
- 内容区：单一区域，A/B 切换时原位替换，不做多页面堆叠。
- 底部：已完成折叠（所有子视图一致）。
- 详情抽屉从右侧覆盖；覆盖时内容区可加轻微遮罩（细化，避免误点）。

### 3.2 模板/子视图切换规则

| 规则 | 说明 | 状态 |
|---|---|---|

| B 子视图 | 今天 / 全部 | 已定 |

| 切换后记忆 | 切换模板再切回时，保留各自上次的子视图与滚动位置 | 细化 |

## 4. 模板 A：时间轴

### 4.1 A-一天（主窗）

```
│ 08:00 ┃
│ 09:00 ┃  ◯  ███████ 晨会 09:00–09:30
│ 10:00 ┃
│ 11:00 ┃  ◯  交周报 11:30
│ 12:00 ┃
│ 15:00 ┃  ◯  ███████ 与张总开会 15:00–16:00
│ ...   ┃
│ 20:00 ┃
│ ────── 轴下方（无时间 / 计数）──────────────────────────
│ ◯ 买牛奶
│ ◔ 喝水   2/3 · 每天
│
│ ▸ 已完成 3
```

**布局规格（细化）**
- 左侧为**时间刻度**：显示范围来自设置中的"主窗 A 时间范围"（默认值待 Q2；跨午夜待 Q2）。
- 轴上：**时间点任务**落在对应时刻（行/点状卡）；**时段任务**显示为跨度的块（高度∝时长），起点终点与刻度对齐；两者都带**行首圆圈**。
- 轴下方独立区域：**无时间任务 + 计数任务**（00 §5："轴下方放无时间/打卡类事项"）；该区域不占时间刻度。
- 任务的完成与编辑：点圆圈 = 完成；点任务本体 = 打开详情抽屉（主窗）。
- 时间范围以外的任务：本视图不显示（数据保留，可在日历/B"全部"看到；细化）。
- 屏幕上放不下时纵向滚动；滚动不改变刻度密度（细化）。

**关键交互（可验收）**
1. 时间点任务位置随时刻变化；时段块起点/终点与刻度对应。
2. 时段任务即使被范围截断也不得裁半条——自动扩边完整显示（见 §4.5 与 AC-F7-5）。
3. 轴下方区域始终存在；无内容时该区域收起（不占空白，细化）。
4. 点圆圈完成、点任务打开抽屉；已完成项从轴上移入底部折叠。
5. 空态见 §12。

### 4.5 时间范围选区（截图式拖选）

**入口**：设置页 →「时间范围（主窗 A）」或「时间范围（悬浮窗 A）」→ 点「框选」。
**主窗与悬浮窗各一套**，互不影响（已定）。

```
┌ 选择主窗显示的时间范围 ─────────────────────────────────────┐
│   08:00 ──────────────────────────────────                  │
│   09:00 ████████████████████████████████  ← 选区外变暗       │
│   12:00 ████████████████████████████████                    │
│   14:45        ▓▓▓ 已自动包含「评审会 14:45–15:30」▓▓▓        │
│   15:30 ████████████████████████████████                    │
│   18:00 ████████████████████████████████                    │
│   20:00 ──────────────────────────────────                  │
│                    [取消]            [确定]                  │
└────────────────────────────────────────────────────────────┘
```

**行为（细化 + 已定约束）**
1. 触发后出现**全屏覆盖层**，显示当天的 24 小时时间标尺与当天任务（背景内容变暗，只保留选区清晰——"像截图"）。（细化）
2. 拖动上/下边界（或拖动选区整体）选择开始–结束时间；选区外变暗。（已定：自由拖选、框外变暗）
3. **边界撞到某时段任务中间时，选区自动扩展到包住该任务完整跨度**（已定：不能裁半条）；扩展时给出可感知提示，如"已自动包含：晨会 09:00–09:30"（细化）。
4. 保存：写回该套配置（主窗/悬浮窗各自独立）；取消：不改动原配置。
5. 是否允许跨午夜、最小可选范围：待定 Q2。
6. **存储的是用户拖选的范围**，"显示时自动扩边包含被截断的任务"还是"保存时扩大范围"：待定 Q2（当前实现建议：保存原始拖选、显示时扩边，但未经确认）。
7. 键盘可达：方向键调整边界，`Enter` 确定、`Esc` 取消（细化，见 §15）。

**验收要点**：主窗/悬浮窗互不影响；撞时段任务完整显示；取消不保存；确定后视图立即按新范围显示（细化）。

## 5. 模板 B：清单

### 5.1 B 行结构与时间文字

```
◯  跟张总开会                                        明天 15:00
◯  买牛奶
◯  喝水                                              2/3 · 每天
```

| 行内元素 | 说明 |
|---|---|
| 行首圆圈 ◯ | 点击 = 完成；计数任务点击 = +1（F6）。键盘焦点可达 |
| 动作标题 | 单行显示，超长省略（抽屉内完整）；必须是动作短语 |
| 时间文字（右侧、弱化） | 按时间字段形态显示，见下表 |

**时间文字格式（细化）**

| 时间形态 | 显示示例 |
|---|---|
| 无时间 | 不显示（空） |
| 仅日期 | `明天` / `11/25`（近 7 天用相对词，更远用日期） |
| 日期 + 时刻 | `明天 15:00` |
| 时段 | `15:00–16:00`（跨天待 Q26） |
| 重复任务 | 叠加重复标记：`每天` / `每周一`（与时间组合显示，如 `周一 09:00 · 每周`） |
| 计数任务 | `2/3 · 每天`（周期为每周时 `2/3 · 每周`） |
| 逾期 | 分组呈现（分组规则待 Q26），不改变状态 |

### 5.2 主窗 B：今天 / 全部

- 子视图切换：顶栏内 `今天 | 全部`（已定：B 可切换今天/全部）。
- 一行一条（已定：勾选圈 + 动作 + 时间文字）；不显示标签/项目/备注/优先级。
- 交互：点圆圈 = 完成；**点行 = 右侧详情抽屉**；底部已完成折叠。
- "全部"= 所有未完成任务（含无时间/计数）。
- "今天"的口径（是否含无时间/计数/逾期）：**待定 Q4**；未定前不得作为验收项。


### 8.3 恢复细节

- 恢复后任务回到未完成视图；时间字段是否保留、落在哪个分组：待 Q5。

- 恢复后**不产生新的创建时间**（细化：保留原创建时间，完成时间清空）。
- 若 Q13 改为"悬浮窗含已完成折叠"：悬浮窗恢复入口与主窗一致（点击恢复、不打开抽屉）；具体交互待 Q13 关闭后回写（不自行定稿）。

## 11. 视觉与动效原则（玻璃极简风）

### 11.1 视觉关键词（已定方向）

透明玻璃、极简、克制、留白、高级感、当代艺术品、晶莹剔透（00 §8）。具体透明度/强调色/字体/动效数值以 `12-visual-spec.md`（v0.2 视觉初稿，待用户确认）为准；本文件只保留原则，不复制数值。

### 11.2 玻璃质感分层（细化原则）

| 层 | 元素 | 视觉要求 |
|---|---|---|
| L0 桌面 | 窗口后面 | 透过玻璃可见，重模糊 |
| L1 主窗内容 | 主页面内容区 | 轻玻璃底 + 足够不透明度保证可读；细高光描边 |
| L2 悬浮窗/抽屉 | 悬浮窗、详情抽屉 | 半透明玻璃、柔和外阴影、1px 高光描边；不抢桌面内容 |
| L3 浮层 | 捕捉条、日历弹窗、选区浮层 | 更清晰的前景层；模糊更重、对比更高 |

- 可读性优先于透明度：文字所在区域必须满足对比度（§15）。
- 不使用重渐变、霓虹色、拟物厚阴影、彩色任务色块、磨砂噪点堆叠（细化，服务于"克制"）。

### 11.3 动效原则

| 场景 | 时长/曲线（细化） | 说明 |
|---|---|---|
| 捕捉条出现 | 120–150ms ease-out | 热键→可见 <150ms（M1），动画不拖慢感知 |
| 捕捉条收起 | 100–150ms | 不阻塞后续操作 |
| 完成勾选/划线 | 120–150ms | 完成反馈轻；不弹确认 |
| 移入已完成折叠 | 150–200ms | 主窗内；悬浮窗完成 ≤1s 消失（已定/规则待 Q24） |
| 详情抽屉滑入/滑出 | 180–220ms ease-out | 覆盖内容，不换页 |
| 日历弹窗/当天清单 | 150–200ms 淡入 + 98%→100% 缩放 | 不夸张 |
| 折叠展开/收起 | 180–220ms | 高度过渡 |
| 视图/模板切换 | 120–180ms 淡入 | 数据同源，弱化切换感 |
| AI 处理中 | 低频微光/呼吸（约 1.2s 循环，低对比） | 不用全屏 spinner、不阻塞 |
| 新任务落位高亮 | 1.5–2s 渐隐 | 告诉用户"接住了"，不弹窗 |

- 全部动效在系统开启"减少动态效果"时降级为纯淡入/直接切换（§15）。
- 不做庆祝彩带、弹跳、抖动、强闪烁（P7）。

### 11.4 深浅色与色彩

- 支持浅色与深色两套玻璃主题（细化方向，具体是否可切换/默认跟随系统待 00 §10.2 确认）。
- 强调色与主题细节未确认（00 §10.2）；v1 先遵循"单一克制强调色 + 中性玻璃底"方向，不引入多套彩色分类。
- 功能色：已完成用弱化（划线/降透明度），删除用低饱和危险色；避免整块红色警报。
- 禁止：红点、角标、优先级色块、任务分类色条（P7；00 §5 视觉克制）。

### 14.3 焦点管理（细化）

1. 打开抽屉/弹窗：焦点移入浮层，并在浮层内循环（focus trap）；关闭后焦点回到触发元素。
2. 捕捉条打开：焦点进入输入区（可直接打字）。
3. 悬浮窗默认**不抢焦点**（细化，待 Q12 确认）。
4. 所有焦点状态必须有清晰可见的焦点环（在玻璃背景上仍可辨识，§15）。

## 15. 可访问性

> 00 §10.8 明确列为待定；以下为本规范提出的 v1 验收基线（细化），需经 Q23 确认后生效。原则：不因为"玻璃/极简"牺牲可用性。

| # | 基线要求 | 可验收方式 |
|---|---|---|
| A1 | 全部核心操作可仅用键盘完成：捕捉、完成、恢复、打开/编辑/删除、切换模板/子视图、框选时间范围 | 纯键盘走查（不碰鼠标） |
| A2 | 所有交互元素有明确可见焦点环（≥3:1 对比，相对玻璃背景仍可辨） | 截图/对比度检查 |
| A3 | 行首圆圈有可访问名称（如"完成：{标题}"）；折叠 header 可读（如"已完成 3 项，展开"） | 屏幕阅读器检查 |
| A4 | 玻璃背景上的文字对比度 ≥ 4.5:1（大字号 ≥ 3:1）；透明度设置不得破坏此线 | 取色验证（浅/深色各一套） |
| A5 | 不依赖颜色单独传达信息：已完成=勾+划线；删除=文字明确"不可恢复" | 视觉检查 |
| A6 | 支持系统"减少动态效果"：所有动效降级为淡入/直接切换 | 系统设置切换验证 |
| A7 | 系统字号缩放/高 DPI 下布局不破、不裁字（悬浮窗同样） | 125%/150%/200% 缩放走查 |
| A8 | 错误/状态信息不只用图标表达（有文字，见 §13） | 走查 |
| A9 | 日历格子、悬浮窗小切换等小目标有足够命中区域（建议 ≥24×24） | 尺寸检查 |
| A10 | 无首启引导时，空态文案承担"怎么用"的最低提示职责（C12/C13） | 产品走查 |

> 结论：A1/A4/A5 建议列为 P0 验收；其余随 Q23 定稿。
