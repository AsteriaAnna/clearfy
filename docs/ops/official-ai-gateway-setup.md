# 官方 AI 服务：从零开始的注册与部署指南（讨论稿）

> 状态：操作预案（等你确认路线后执行）
> 日期：2026-11-01
> 适用：想给"任何人安装了就能用"提供 AI 能力（官方服务路线 B），或先给朋友小范围内测
> 相关：`docs/adr/0001-ai-service-model.md`

---

## 0. 先说结论

1. **你不用买云服务器。** 这个规模用"云函数（Serverless）"就够了，按量付费、几乎零运维。
2. **需要注册两类网站：**
   - **模型厂商**（必须）：阿里云百炼 / 火山引擎 / 腾讯云 / DeepSeek / OpenAI 等，拿来跑语音识别和解析；
   - **云平台**（只有走"官方服务"路线才需要）：阿里云 / 腾讯云（实名 + 支付宝/微信）。
3. **域名不是必须的**：内测阶段用云函数自带的 HTTPS 地址即可；公开分发时再考虑域名（国内自定义域名要备案，2~4 周）。
4. **模型费用不是固定月费**，是"预充值 + 按量扣费"；只有云服务器才是固定月费。
5. **建议顺序**：先用模型厂商 Key + 本地跑通（成本几块/月）→ 朋友内测再加云函数（几十~一两百/月）→ 验证有需求、想清楚了收费和合规，再扩大。

---

## 1. 三条路线，对应你要注册/花钱的东西

| 路线 | 要注册 | 要买服务器吗 | 月成本粗估（单位：元） |
|---|---|---|---|
| 自用验证（现在推荐） | 模型厂商 1 个 | 不用 | 5~20（纯 API，按量） |
| 朋友内测（≤20 人） | 模型厂商 + 阿里云函数计算（同账号） | 不用 | 50~200（API 为主，函数计算几元） |
| 公开发布（100+ 活跃） | 上面 + 数据库/额度系统 + 域名（可选） | 可选（VPS ¥24~60/月） | 500~2000+，取决于用量与收费 |
| 内置作者 Key 自用 | 模型厂商 | 不用 | 几条风险：别公开分发 |

> 成本为粗略量级，按厂商现价与实际使用量核算。

## 2. 阶段一：自用验证（不需要任何服务器）

### 注册模型厂商（以阿里云百炼为例，约 10~20 分钟）

1. 打开 [阿里云](https://www.aliyun.com/) 注册账号 → 完成**实名认证**（个人：身份证 + 人脸）。
2. 搜索并开通「**百炼（Model Studio）**」。
3. 在百炼控制台创建 **API Key**（注意：创建后只显示一次，复制保存）。
4. 领取新用户免费额度（通常有；以官网为准）；后续按量扣费可以充 50 元起步。
5. 你在客户端「AI 设置」里填入 Key → 点「测试连接」→ 跑 10 条自己的语音验证效果。

**同账号可同时用**：Qwen 系列（解析）+ Paraformer/SenseVoice 系（语音识别）——所以只填一个 Key。
（火山引擎 = 豆包 + 语音识别，腾讯云 = 混元 + 一句话识别，OpenAI = GPT + gpt-4o-transcribe，也可，但国内访问/支付门槛不同。）

### 如果只想自己/家人用

- 可以把 Key 放在本机配置里，**不要**把它打进安装包发给别人；
- 在厂商控制台设置**消费预算/告警**（例如每月 50 元封顶），把最坏情况封住。

## 3. 阶段二：朋友内测（轻量服务怎么做）

### 轻量服务 = 一个很小的转发程序

```
朋友的 Clarify ──HTTPS──► 你的网关（云函数） ──► 模型厂商 API
                            ├─ 校验邀请码/设备
                            ├─ 每人每天调用上限
                            ├─ 转发语音/文本
                            └─ 记录用量（不保存音频）
```

它的全部职责就四件事：**藏住 Key、验证谁能用、限制用多少、把请求转发出去**。

### 部署方式对比（推荐第一个）

| 方式 | 要不要运维 | 成本 | 适合 |
|---|---|---|---|
| **云函数（阿里云函数计算 FC / 腾讯云云函数）** | 几乎零运维 | 按量，几元/月，常有免费额度 | **推荐**：内测/小规模 |
| 一体化 Serverless（腾讯云开发 CloudBase） | 低 | 低 | 不想分别折腾数据库 |
| 轻量应用服务器（阿里云/腾讯云） | 要自己管 Linux/安全更新 | ¥24~60/月固定 | 以后量大、想固定成本 |
| 海外托管（Cloudflare Workers / Vercel） | 低 | 低/免费 | 海外用户为主；国内访问不稳 |

### 具体步骤（阿里云，函数计算 FC）

1. 用同一个阿里云账号，开通「**函数计算 FC**」。
2. 新建函数（Node.js 或 Python 运行时），上传我给你的部署包（包含网关代码）。
3. 配置**环境变量**：模型厂商 Key、邀请码列表、每设备每日额度（Key 只存在这里，永远不下发客户端）。
4. 创建 **HTTP 触发器**，拿到一个 `https://...` 地址。
5. 客户端「AI 网关地址」填这个 URL，首次使用输入邀请码。
6. 先用 1~2 台设备验证；在费用中心设置**预算告警**（例如每月 200 元）。
7. 看函数日志排查错误；用量可以先用日志统计，后续再加数据库。

### 网关最小功能清单（我负责写）

- `POST /v1/parse`：文本 → 模型 → 待办 JSON（校验/重试/降级）
- `POST /v1/transcribe`：短音频 → 语音识别（选同步 HTTP 接口的厂商，减少复杂度）
- 邀请码/设备校验；每设备每日限额；请求日志（不含音频原文）
- Key 只从环境变量读取；不落盘音频；错误统一返回可读文案
- 可先在**本机 localhost 跑通**，再上云——这一步不需要任何云账号

> ⚠️ 一个技术注意：云 ASR 的接口形态不同。优先选**同步 HTTP 短音频接口**（一次上传，1~2 秒返回）；如果某厂商只有 WebSocket 流式，网关要额外代理 WebSocket，工作量更大。具体选哪家，用你的真实录音在 spike 里对比再定（阿里云非实时的 Paraformer HTTP 是"异步任务+轮询"，不适合对话式交互，需用其实时/一句话识别接口）。

## 4. 阶段三：公开发布（再考虑这些）

- **正式服务**：云函数 + 数据库（额度/设备记录）+ 监控 + 防刷；或固定成本 VPS。
- **域名**：内测不需要；公开建议有。国内自定义域名需要 ICP 备案（免费，约 2~4 周），海外域名另说。
- **收费模式**：免费额度 + 订阅/买断，否则 API 账单会随用户量线性增长。
- **合规（重要，非法律意见）**：面向公众提供生成式 AI 服务，国内涉及**生成式 AI 服务备案/安全评估**、隐私政策、用户协议等义务；个人开发者作为服务主体可能较难，公开上架前必须专门评估。**自用或极小范围内部测试一般不涉及**，但也要做隐私告知（录音会上传厂商）。
- **隐私**：网关不保存音频；不记录用户待办内容；隐私政策写清楚"哪些数据发给哪个厂商"。
- **降低风险的做法**：BYOK 模式（用户自带 Key）可以完全绕开"你提供服务"的合规与成本责任，很多开源 AI 桌面工具都这么做。

## 5. 你要准备/决定的事（清单）

- [ ] 模型厂商选哪家？（建议先阿里云百炼：LLM+ASR+函数计算一个账号）
- [ ] 是否接受实名认证 + 支付宝/微信充值？
- [ ] 第一阶段先"自用验证"还是直接"内测网关"？
- [ ] 内测人数上限（建议 ≤10 人）与每人每日额度（建议 ≤200 次）
- [ ] 每月预算上限（建议先设 200 元告警）
- [ ] 是否要域名（内测不需要）
- [ ] 如果公开发布：是否接受备案/隐私/收费这一整套责任；还是改回 BYOK

## 6. 时间预期

| 事项 | 时间 |
|---|---|
| 模型厂商注册 + 实名 + Key | 10~20 分钟 |
| 本地客户端接入 + 测试 | 半天~1 天（我写） |
| 云函数部署 + 联调（有部署包+图文） | 30~60 分钟 |
| 域名购买 + 备案（仅公开） | 2~4 周 |
| 合规评估（仅公开） | 数周，需专业意见 |
